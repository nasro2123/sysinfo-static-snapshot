# SysInfo Digital Products

هذا المشروع عبارة عن صفحة ويب مستقلة مبنية من الصفر لعرض خدمات ومنتجات رقمية. لا يعتمد المشروع على ملفات أو صور أو نصوص أو JavaScript أو CSS من أي موقع خارجي.

## التشغيل المحلي

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات ثابتًا:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

## النشر

يُنشر المشروع تلقائيًا على GitHub Pages عند تحديث الفرع `master` باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.

## الخصوصية والاستقلالية

جميع أنماط التصميم والمحتوى والواجهة موجودة داخل هذا المستودع. لا توجد روابط إلى النطاق الأصلي، ولا إلى شبكات CDN، ولا إلى صور أو مكتبات خارجية. وظائف الدفع وتسجيل الدخول غير مضمّنة في هذه النسخة المستقلة.

## الترخيص

يُرجى إضافة الترخيص المناسب قبل إعادة توزيع المشروع أو استخدامه تجاريًا.
